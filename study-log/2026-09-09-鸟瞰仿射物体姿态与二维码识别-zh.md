## 0. 一句话总结

> **鸟瞰仿射 = 把倾斜图“拉平”成俯视（四点变换）；姿态角度 = 物体中心 + 旋转角（夹爪要对准才夹得稳）；二维码识别 = 现成 API 零训练给物体“身份”。** 三个都是让机械臂“看清并认出”物体的实用工具。

---

## 1. 核心知识点（对照 109–111）

### 1.1 109 鸟瞰图仿射变换
- 用**四点仿射**（`getPerspectiveTransform` + `warpPerspective`）把倾斜拍摄的桌面“拉平”成俯视，方便后续量坐标、算距离（接 Day 23 比例尺）。
- **四点顺序错 → 图像扭曲**，必须按“左上→右上→右下→左下”对应。

### 1.2 110 获取被抓取物体的姿态角度信息
- 由轮廓的**最小外接矩形**得到“中心 + 旋转角”；抓的时候让夹爪转到同一角度才夹得稳。
- **旋转角定义（相对哪个轴）要一致**，否则姿态错、夹歪。

### 1.3 111 OpenCV 二维码识别
- 用现成 API（如 `cv2.QRCodeDetector` 或 `pyzbar`）直接解码，得到字符串（URL / 编号）。
- 相当于给物体贴“身份证”，机械臂按码分类 / 抓取——**零训练、即开即用**。

---

## 2. 原理（先抓这几条）

1. **仿射 = 保平行的直线变换**，用来做透视矫正（斜→正）。
2. **姿态 = 中心 + 角度**；夹爪要对准角度才夹得稳，否则滑脱。
3. **二维码 = 现成解码**，不用自己训练模型就能给物体“身份”。

## 5. 常见误区 & 容易踩的坑

| # | 误区 | 真相 |
|---|---|---|
| 1 | 仿射四点随便排 | 顺序错 → 图像扭曲 |
| 2 | 旋转角定义不清 | 姿态错、夹歪、滑脱 |
| 3 | 自己造二维码识别 | 有现成 API，别重复造轮子 |
| 4 | 斜图直接量距离 | 没仿射矫正 → 透视畸变，距离算错 |
