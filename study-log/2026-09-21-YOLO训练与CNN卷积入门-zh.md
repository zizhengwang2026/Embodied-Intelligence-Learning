## 0. 一句话总结

> **训练看两条线：loss 要降、mAP 要升；loss 降而 mAP 不升多半是过拟合（数据太少/太单一）。** 而 CNN 之所以能“看见”，是因为**卷积核像一个个小模板，在图上滑动找特定图案**——浅层找边缘/角点，深层拼出“眼睛”“轮子”这类部件。

## 1. 核心知识点（对照 151–154）

### 1.1 151 YOLO 训练的演示
- 启动训练（Ultralytics）：
  ```python
  from ultralytics import YOLO
  model = YOLO('yolov8n.yaml')   # 从结构开始训
  # 或 YOLO('yolov8n.pt')       # 从预训练权重微调（推荐，收敛快）
  model.train(data='dataset.yaml', epochs=50, imgsz=640, batch=8)
  ```
- **关键超参**：`epochs`（轮数）、`batch`、`imgsz`、`lr0`（初始学习率，呼应 Day 31）。
- 产出在 `runs/detect/train*/`：`weights/best.pt`、`results.png`（曲线）、混淆矩阵等。

### 1.2 152 YOLO 推理效果的展示
- 用训好的 `best.pt` 对新图推理，肉眼评估效果。
- **量化看 mAP**（mean Average Precision）：综合考虑了不同置信度阈值下的 P/R 表现（Day 36 的进阶版）。
- **发现问题 → 回头补数据**（哪类差就补哪类），建模是循环（Day 30）。

### 1.3 153 CNN 卷积入门
- 为什么不用全连接处理图像：28×28 拉平尚可，**640×640 的图拉平就是 40 万维**，参数爆炸且丢失空间结构。
- **CNN 用“局部连接 + 权值共享”**：每个卷积核只看一小块（如 3×3），并在全图共享参数 → 参数量骤降、且对平移更鲁棒。

### 1.4 154 卷积核的工作原理
- **卷积 = 拿一个小模板在图上滑，逐位相乘求和**，输出值越大说明这块越像模板。
- 不同核检测不同特征：有的找竖边、有的找横边、有的找斑点。
- **浅层核→边缘纹理；中层→部件；深层→语义物体**（这就是“自动特征工程”，呼应 Day 33）。
- 输出尺寸公式（记一下）：`out = (in + 2·padding − kernel) / stride + 1`。

## 2. 原理（先抓这几条）

1. **训练看 loss 与 mAP 两条线**，过拟合的典型表现是 loss 降但 val/mAP 不涨。
2. **卷积 = 滑动模板匹配**，权值共享让参数量可控。
3. **CNN 的层次 = 自动特征工程**：从边缘到部件到物体。

## 5. 常见误区 & 容易踩的坑

| # | 误区 | 真相 |
|---|---|---|
| 1 | 只看 loss 下降就放心 | 要看 mAP/验证指标，loss 降但 val 不涨 = 过拟合 |
| 2 | 数据少就堆大模型 | 数据少 + 大模型 = 过拟合更快；应先补数据或用预训练微调 |
| 3 | 一上来从零训 | 用预训练权重微调，收敛快、效果好 |
| 4 | 卷积输出尺寸靠猜 | 用公式算：`(in + 2p − k)/s + 1` |
| 5 | 以为卷积核是人设计的 | 核的权重是**训练学出来的**，不是手工写的 |
